# Старт: что сделать руками до того, как Claude начнёт писать расширение

Время: около часа, из них 10–40 минут — выгрузка БП в файлы.

## 1. Скачать учебную Бухгалтерию

1. Открыть https://online.1c.ru/catalog/free/34690674/ — «1С:Бухгалтерия 8. Учебная версия» (бесплатно).
2. Заполнить анкету, согласиться с лицензией, скачать архив.
3. В архиве: учебная платформа + конфигурация «Бухгалтерия предприятия 3.0» + книга (PDF).

## 2. Установить

1. Распаковать архив, запустить `setup.exe`.
2. Если установщик ставит платформу другой версии, чем 8.3.27.1508, — ничего страшного,
   скрипты проекта сами найдут самую новую учебную платформу.
3. Шаблон конфигурации БП установится в каталог шаблонов 1С.

## 3. Создать базу

1. Запустить 1С → «Добавить» → «Создание новой информационной базы».
2. Выбрать из шаблона «Бухгалтерия предприятия» (если есть вариант **демо** — выбрать его).
3. Каталог базы: **`C:\1c\bp_ucheb`** (если другой — поправить `.1c-devbase.ps1`).
4. **Запустить базу в режиме 1С:Предприятие один раз** и дождаться окончания первоначального
   заполнения / обновления данных. Без этого БСП не работает.
5. Если при запуске спрашивает пользователя — запомнить имя (например «Администратор») и вписать его
   в `$ONEC_USER` в `C:\Dev\Reklamacii\.1c-devbase.ps1`.
6. Закрыть 1С:Предприятие.

## 4. Создать расширение и заимствовать объекты

1. Открыть базу в **Конфигураторе** → Конфигурация → «Открыть конфигурацию».
2. Конфигурация → «Расширения конфигурации» → «Добавить»:
   - Имя: **`Рекламации`** (ровно так)
   - Синоним: `Рекламации покупателей`
   - Префикс: **`рек_`**
   - Назначение: **Адаптация**
3. Открыть конфигурацию расширения (двойной щелчок по нему в списке).
4. В дереве **основной** конфигурации по каждому объекту: ПКМ → «Добавить в расширение» → выбрать `Рекламации`:
   - Документы → **РеализацияТоваровУслуг**
   - Справочники → **Контрагенты**, **Номенклатура**, **Организации**, **Пользователи**
5. Сохранить расширение, затем «Обновить конфигурацию базы данных» (F7).
6. **Закрыть Конфигуратор** (учебная версия — только один сеанс).

> Если Конфигуратор не даёт создать расширение или менять что-то — сфотографируйте сообщение и
> пришлите в чат, переиграем.

## 5. Выгрузить в файлы

В папке `C:\Dev\Reklamacii`:

1. `dump-base.bat` — выгрузка основной конфигурации БП в `base-src\`. Долго, окно не закрывать.
2. `dump.bat` — выгрузка расширения в `src\`.
3. Git: открыть терминал в папке и выполнить
   ```
   git init
   git config core.autocrlf false
   git config core.longpaths true
   git add .
   git commit -m "Пустое расширение Рекламации с заимствованными объектами"
   ```

Если что-то упало — лог лежит рядом (`dump-base.log`, `dump.log`).

## 6. Написать в чат «готово»

Дальше Claude пишет этап 1 в `src\`, вы запускаете `load.bat` и проверяете в 1С:Предприятии.
